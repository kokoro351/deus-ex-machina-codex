# Codex編集ガイド

## まず覚えること

このゲームは React/Vite で動きます。

React は「画面を部品に分けて作る仕組み」です。
Vite は「開発中にブラウザで素早く確認する仕組み」です。

つまり React/Vite 構成とは、ゲームをブラウザで動かしながら編集しやすくするための形です。

## Codexに頼みやすい依頼例

```text
src/data/scenes.js の turn-flood に選択肢を1つ追加して。
選択肢名は「隔壁を半分だけ閉じる」。
次のシーンも追加して、安定性は少し上がるが人間性も少し残る展開にして。
```

```text
エンディング end-collapse の文章をもっと静かで怖い雰囲気に直して。
コード構造は変えないで。
```

```text
画面の横幅を少し広くして、スマホでは今のまま見やすくして。
```

## シナリオを編集する場所

`src/data/scenes.js` を開きます。

1つのシーンはだいたいこういう形です。

```js
"turn-flood": {
  id: "turn-flood",
  type: "choice",
  turn: 1,
  title: "浸水",
  image: imageSet.gameplay,
  body: [
    "ここに本文を書きます。",
    "2行目も書けます。",
  ],
  choices: [
    { label: "選択肢名", next: "次のシーンID", note: "変化メモ" },
  ],
}
```

## やってはいけないこと

- `id` を重複させない
- `next` に存在しないシーンIDを書かない
- 文字列の前後の `"` や `,` を消さない
- `src/components` を触るときは、見た目や動作を変えたい時だけにする

## 変なことを言ってしまったら

大丈夫です。Codex にこう聞いてください。

```text
今のお願い、変だったら初心者向けに直してから作業して。
```

Codex側で、危なそうな変更や意味が通らない依頼は確認してから進めるのがよいです。
