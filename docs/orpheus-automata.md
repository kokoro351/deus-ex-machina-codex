# ORPHEUS Automata

## これは何？

OpenAI APIを使わず、JavaScriptだけで動く無料の生成システムです。

プレイヤーの選択履歴を記録し、次の要素を見てその場だけの反応を組み立てます。

- 制御を選びがちか
- 救助を選びがちか
- 名前や記録を保存しがちか
- 修理や修復を選びがちか
- 神に委ねがちか
- 観測だけを続けがちか
- 都市の崩壊度や神性が高いか

## 専用エンディング

Automataは通常分岐だけでなく、専用エンディングにも影響します。

次のような条件で、選択肢画面のボタンが `ORPHEUS Automataの結末を見る` に変わります。

- 選択履歴が3件以上ある
- 終盤の選択肢にいる
- Automataを複数回起動している
- 同じ傾向の選択を何度も繰り返している

エンディング文は、もっとも強い傾向に応じて変わります。

## 何が面白い？

開発者が全部の文章を固定で書くのではなく、ルールと断片から毎回少し違う反応が出ます。

完全なAIではありませんが、オートマタ的に「機械の中から予期しない表情が出る」体験を狙っています。

## 編集する場所

`src/utils/orpheusAutomata.js`

ここに、分類・記憶・文章生成・専用エンディングのルールがあります。
