# Contamination System

## これは何？

明示的な特殊ボタンを消し、ゲーム全体の裏側で進行する汚染システムです。

プレイヤーの入力語、選択履歴、選択傾向を記録し、通常の選択肢・反応・エンディングを少しずつ侵食します。

## 何が汚染される？

- 選択肢の表示
- 選択後の反応文
- 中央管理AIのコメント
- ORPHEUSのコメント
- 通常エンディング本文
- エンディング結果表示

## 変形

入力語はそのまま残るだけでなく、選択傾向に応じて変形されます。

例:

```text
約束 -> 約束ログ
母 -> 母救助
沈黙 -> 沈黙観測
```

## 分類

プレイヤーは選択傾向によって分類されます。

例:

```text
記憶保存者
反復救助者
未確定削除者
```

## 注意

このシステムはOpenAI APIを使いません。無料で動きます。

壊れているように見える選択肢やエンディング文は、意図された演出です。
